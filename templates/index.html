Documentación de API

GET /api/accounts/{customer_id}

Obtener información de cuenta del cliente especificado

Parámetros: customer_id (parámetro de ruta) - ID del cliente
POST /api/transfer

Ejecutar operación de transferencia

Cuerpo de la solicitud: 
{
  "sender_account_id": "string",
  "recipient_account_id": "string", 
  "amount": number,
  "description": "string"
}
POST /api/purchase

Procesar pago de compra

Cuerpo de la solicitud: 
{
  "account_id": "string",
  "merchant_id": "string",
  "item_name": "string",
  "amount": number
}
